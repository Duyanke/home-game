# 家务神兽养成游戏设计文档

## 项目概述

### 产品定位
一款面向家庭的安卓应用游戏，通过将家务任务与神兽养成结合，激励家庭成员积极参与家务劳动。家庭成员做家务越多，自己养的神兽成长越快，神兽之间可以进行策略性决斗。

### 核心特性
- 全员平等：所有家庭成员可创建任务、养神兽、参与决斗
- 局域网同步：多设备通过局域网连接，不依赖云端服务器
- 中国神话风格：五种传统神兽可选（青龙、朱雀、白虎、玄武、麒麟）
- 策略决斗：回合制战斗，玩家选择技能，有克制关系

### 技术选型
- 开发框架：Flutter（跨平台，支持 Android/iOS）
- 数据存储：SQLite（服务器端集中存储）
- 通信方式：TCP Socket（局域网实时通信）
- 状态管理：Provider

### 设备角色分配

首次使用流程：
1. 用户打开 App，检测是否已有家庭服务器广播
2. 发现服务器 → 加入现有家庭（输入家庭码）
3. 未发现服务器 → 创建新家庭，本设备成为家庭服务器，生成家庭码

### 家庭码机制
- 格式：6位数字+字母组合（如：A3K9B7）
- 生成时机：创建家庭时自动生成
- 用途：其他成员输入家庭码加入
- 有效期：永久有效，除非重新创建家庭

### 家庭成员限制
- 无数量限制，任意数量家庭成员可加入同一家庭组

## 神兽设计

### 属性系统

每个神兽有以下核心属性：
- **生命值 (HP)**：战斗时承受伤害的能力
- **攻击力 (ATK)**：普通攻击的伤害值
- **防御力 (DEF)**：减少受到的伤害
- **速度 (SPD)**：决定战斗中的行动顺序
- **能量点 (EP)**：技能消耗资源，初始100，每回合恢复+10，上限200

### 五种神兽初始属性

| 神兽 | 元素属性 | HP | ATK | DEF | SPD | 特点 | 初始技能(EP消耗) |
|------|----------|-----|-----|-----|-----|------|------------------|
| **青龙** | 木/风 | 120 | 75 | 55 | 110 | 速度型，先手优势 | 风刃斩(25EP) |
| **朱雀** | 火 | 100 | 95 | 50 | 80 | 攻击型，爆发伤害 | 烈焰冲击(30EP) |
| **白虎** | 金/雷 | 130 | 85 | 70 | 90 | 平衡型，均衡发展 | 霜牙咬(20EP) |
| **玄武** | 水/土 | 150 | 60 | 85 | 70 | 防御型，持久战 | 坚岩壁垒(15EP) |
| **麒麟** | 光 | 110 | 65 | 65 | 85 | 辅助型，团队增益 | 祥瑞之光(35EP) |

### 神兽进阶技能详情

| 神兽 | 进阶技能1(EP消耗) | 进阶技能2(EP消耗) | 技能效果 |
|------|------------------|------------------|----------|
| **青龙** | 龙啸天地(50EP) | 御风护盾(30EP) | 群攻150%伤害 / 本回合减伤40% |
| **朱雀** | 焚天烈焰(45EP) | 涅槃重生(60EP) | 单体200%伤害 / 战败时复活一次(HP50%) |
| **白虎** | 虎啸雷霆(40EP) | 金刚护体(25EP) | 单体150%伤害+眩晕概率 / 本回合防御+100% |
| **玄武** | 冰封护盾(35EP) | 玄武之力(45EP) | 免疫本回合伤害 / 受击时反击50%伤害 |
| **麒麟** | 圣光治愈(40EP) | 祥瑞赐福(55EP) | 回复HP30% / 全属性提升20%持续3回合 |

### 技能克制关系

- 木(青龙) → 克制 → 土(玄武) 【风破岩】
- 土(玄武) → 克制 → 水 【岩挡水】
- 水 → 克制 → 火(朱雀) 【水灭火】
- 火(朱雀) → 克制 → 金(白虎) 【火熔金】
- 金(白虎) → 克制 → 木(青龙) 【金断木】
- 光(麒麟) → 不参与克制循环，对所有元素伤害减半

### 成长阶段

| 阶段 | 名称 | 累计积分门槛 | 外观变化 | 技能解锁 |
|------|------|--------------|----------|----------|
| 1 | 幼年期 | 0积分（初始） | 小型萌态形态 | 基础技能x1 |
| 2 | 成年期 | 500积分 | 形态变大，气势增强 | 基础技能+1个进阶技能 |
| 3 | 进化期 | 1500积分 | 带元素特效 | 全技能解锁 |
| 4 | 神圣期 | 3000积分 | 全身发光，元素特效强化 | 技能威力+30% |

## 家务任务系统

### 任务类型

**预设任务（系统内置）：**
- 扫地/拖地：10积分
- 洗碗：15积分
- 整理房间：20积分
- 洗衣服：15积分
- 倒垃圾：5积分
- 擦窗户：15积分
- 照顾宠物：20积分
- 准备早餐：25积分
- 清洁卫生间：30积分

**自定义任务：**
- 任务名称（用户输入）
- 积分值（创建者设置：5-50分）

### 任务流程

```
待完成(待领取) → 进行中(已领取) → 待确认(等待审核) → 已完成
                                                      │
                                                      ▼
                                               执行者获得积分
                                               神兽自动成长进度
```

### 任务确认机制
任意成员确认：家庭组中任意其他成员（非执行者本人）点击确认即可让执行者获得积分。

### 积分规则
- 任务完成后积分立即计入执行者的累计积分
- 累计积分作为神兽成长阶段突破的判断依据
- 家庭内显示成员积分排名

## 神兽决斗系统

### 决斗发起流程
客户端A发起决斗请求 → 服务器转发邀请 → 客户端B接受/拒绝 → 开始决斗回合

### 回合流程（策略选择制）

1. **速度判定**：SPD高的神兽先行动，若相同则随机
2. **先手方选择**：普通攻击、使用技能、防御姿态、使用道具
3. **计算伤害**：
   - 基础伤害 = ATK × 技能倍率
   - 实际伤害 = 基础伤害 - DEF
   - 克制加成：克制时 +50%伤害
   - 防御姿态：受到伤害减半
4. **后手方选择**：同上
5. **回合结束判定**：任一方HP≤0 → 战斗结束，否则进入下一回合

### 战斗选项

| 选项 | 效果 |
|------|------|
| 普通攻击 | 100% ATK伤害，无消耗 |
| 技能攻击 | 技能倍率伤害，消耗EP |
| 防御姿态 | 本回合受到伤害减半 |
| 使用道具 | 回血/增益，消耗道具库存 |

### 决斗奖励

| 战斗结果 | 获胜方 | 失败方 |
|----------|--------|--------|
| 胜利 | 50积分 + 获胜记录 | 无积分 |
| 平局 | 25积分 | 25积分 |
| 投降 | 20积分 | 0积分 |

连胜奖励：连胜3场以上，额外获得10积分/场

## 局域网通信

### 传输层：TCP Socket

| 消息类型 | 方向 | 说明 |
|----------|------|------|
| HELLO | 客户端→服务器 | 加入家庭请求 |
| HELLO_ACK | 服务器→客户端 | 加入确认 |
| SYNC_REQUEST | 客户端→服务器 | 请求数据同步 |
| SYNC_DATA | 服务器→客户端 | 返回数据快照 |
| TASK_CREATE | 客户端→服务器 | 创建新任务 |
| TASK_UPDATE | 客户端→服务器 | 任务状态变更 |
| BROADCAST | 服务器→所有客户端 | 广播变更通知 |
| DUEL_INVITE | 客户端→服务器 | 发起决斗邀请 |
| DUEL_ACCEPT | 客户端→服务器 | 接受决斗 |
| DUEL_ACTION | 双方→服务器 | 决斗回合操作 |
| HEARTBEAT | 双向 | 保持连接活跃 |

### 消息格式（JSON）

```json
{
  "type": "TASK_CREATE",
  "payload": {
    "taskId": "uuid-123",
    "name": "扫地",
    "points": 10,
    "creatorId": "member-001"
  },
  "timestamp": 1710503400
}
```

### 断线重连
- 心跳超时30秒视为断线
- 服务器标记成员"离线"状态
- 重连时发送 SYNC_REQUEST 获取最新数据

### 服务器离线处理
- 客户端显示"服务器离线"提示
- 本地缓存操作，重连后同步
- 设置页面可"迁移服务器角色"到其他设备

## 数据存储

### SQLite 表结构

```sql
-- 家庭信息表
CREATE TABLE families (
    family_id TEXT PRIMARY KEY,
    family_code TEXT UNIQUE NOT NULL,
    server_device_id TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 家庭成员表
CREATE TABLE members (
    member_id TEXT PRIMARY KEY,
    family_id TEXT NOT NULL,
    name TEXT NOT NULL,
    device_id TEXT NOT NULL,
    beast_id TEXT,
    total_points INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    status TEXT DEFAULT 'offline'
);

-- 神兽表
CREATE TABLE beasts (
    beast_id TEXT PRIMARY KEY,
    member_id TEXT NOT NULL,
    beast_type TEXT NOT NULL,
    stage INTEGER DEFAULT 1,
    hp INTEGER NOT NULL,
    atk INTEGER NOT NULL,
    def INTEGER NOT NULL,
    spd INTEGER NOT NULL,
    ep INTEGER DEFAULT 100,
    unlocked_skills TEXT
);

-- 任务表
CREATE TABLE tasks (
    task_id TEXT PRIMARY KEY,
    family_id TEXT NOT NULL,
    name TEXT NOT NULL,
    points INTEGER NOT NULL,
    creator_id TEXT NOT NULL,
    assignee_id TEXT,
    executor_id TEXT,
    status TEXT DEFAULT 'pending',
    is_custom BOOLEAN DEFAULT FALSE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    completed_at DATETIME,
    confirmed_by TEXT
);

-- 决斗记录表
CREATE TABLE duels (
    duel_id TEXT PRIMARY KEY,
    challenger_id TEXT NOT NULL,
    defender_id TEXT NOT NULL,
    winner_id TEXT,
    result TEXT DEFAULT 'ongoing',
    rounds INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    ended_at DATETIME
);
```

### 数据同步策略

| 数据类型 | 同步时机 | 同步方式 |
|----------|----------|----------|
| 家庭成员 | 加入/离开时 | 全量同步 |
| 神兽信息 | 成长/战斗后 | 增量同步+广播 |
| 任务数据 | 创建/完成时 | 增量同步+广播 |
| 决斗状态 | 每回合操作时 | 实时双向通信 |

## 成功标准

1. 家庭成员可通过家庭码加入同一家庭组
2. 所有成员可创建、领取、完成家务任务并获得积分
3. 神兽根据累计积分自动成长，解锁新技能和新形态
4. 神兽之间可进行策略性决斗，结果正确计算并记录
5. 局域网内多设备数据实时同步
6. 断线重连后数据正确恢复
